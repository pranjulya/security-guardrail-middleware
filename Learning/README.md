# Learning guide

Start with [learning path](learning-path.md), then read each concept before its phase. Demonstrate understanding by predicting a failure, writing a synthetic case and explaining the observed result. A working detector with unexplained false positives is not completion.

Concepts: [trust boundaries](concepts/trust-boundaries.md), [PII and spans](concepts/pii-and-spans.md), [evaluation](concepts/evaluation-and-tradeoffs.md). Exercises: [indirect injection](scenarios/indirect-injection.md), [redaction outage](scenarios/redaction-outage.md), [false positives](scenarios/false-positive-review.md). Prepare with [interview Q&A](interview/questions-and-answers.md).
